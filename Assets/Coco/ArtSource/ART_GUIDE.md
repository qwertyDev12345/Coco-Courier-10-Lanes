# Pixel art production notes

Generated with the built-in image_gen tool. Five production atlases are stored in Assets/Coco/Resources/PixelArt, not linked to a tool cache.

The generator returned 1254 x 1254 PNG files (rather than the requested 1024 squares). PixelArt.cs uses measured atlas regions and alpha-trims individual sprites. SpriteRenderer and UI images fit their assigned world/UI bounds with preserved aspect. Texture imports use Point filtering, no mipmaps and uncompressed alpha. UI frames use nine-slice borders; the title is baked pixel lettering. All changing labels and values remain English text in Pixelify Sans.

## Display targets at 540 x 960
- Courier: 1.3 world units, about 73 screen pixels tall, versus the original 25px primitive. Four poses are included in both Classic and Sunrise bag variants; idle, airborne and delivered are used, rear-view is available for future movement.
- Cars: up to 1.44 x 0.8 world units, about 81 x 45px; direction mirrors the same car sprite.
- World clients: up to 1.15 x 1.5 world units; larger portraits appear in the HUD and result.
- Menu courier: fits a 122 x 125px portrait region; food icons fit the existing shop rows.
- UI: uses the existing 540 x 960 reference layout and safe area. Nine-slice frames adapt to portrait aspect ratios instead of stretching baked text.
- Camera: 9.6 world units across in portrait, sufficient approach visibility while making the courier readable.

## Clients
Office clerk, builder, doctor, chef, mechanic, teacher, gardener, executive. The client advances after a successful delivery using the persisted delivery count modulo eight; retries keep the current client.

## Font
Pixelify Sans, official Google Fonts source: https://github.com/google/fonts/tree/main/ofl/pixelifysans . Font is bundled with its OFL.txt license under Resources/Fonts.
